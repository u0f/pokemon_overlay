# Logo de PokeStream

- PNG transparente: `assets/pokestream-logo.png`.
- Icono de Windows: `assets/pokestream.ico`, con tamaños 16, 24, 32, 48, 64, 128 y 256 píxeles.
- El README usa el PNG; scripts/build.ps1 incrusta el ICO en PokeStream.exe.
- Generado con la herramienta integrada ImageGen. El ICO es una conversión de formato del PNG, conservando la transparencia.

## Prompt de generación

Use case: logo-brand. Asset type: original application logo for PokeStream, a local Pokémon streaming overlay application; square Windows executable icon and GitHub README emblem. Design one single crisp centered icon on a genuinely transparent background. A bold custom geometric capital P incorporating a small play triangle in its bowl, inside a mint green rounded square with subtle dark forest-green inset detailing. Match the existing application's mint #55edb0 and near-black #101715 palette. Flat vector-like professional software logo, thick clean contours, no gradients, no shadows, no texture, no mockup. Compact high-contrast silhouette readable at 16px, little empty padding around the rounded-square mark. Only letter P, no wordmark, no other text, no Pokémon characters or copyrighted logos, no Pokéball. One logo only, square composition.
